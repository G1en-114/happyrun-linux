# 路网编辑器使用说明

双击 `路网编辑器.html` 即可打开（需与 `bg-sat.png`、`bg-road.png` 放在同一文件夹）。

## 这是什么

一个照着**真实卫星图**手工精修路网的编辑器。底图为高德 z18 卫星/道路瓦片（GCJ-02），
与乐跑 App 的坐标系**严格 1:1**——在这里对齐到的位置，跑完在小程序里的显示位置就是一样的。
底图覆盖整个明向校区 + 西河 + 南河 + 四周余量（3328×3328 像素，约 1570×1570 米）。

## 界面

- 顶栏工具按钮：平移/缩放、移动节点、加点/连线、删除、水域多边形、建筑多边形
- 图层开关：卫星图 / 道路图（两者可叠加对照）/ 水域 / 建筑 / 打卡点
- 底部状态栏：光标经纬度、节点/边/水域/建筑数量、比例尺

## 常用操作

| 操作 | 方法 |
|---|---|
| 平移 | 按住左键拖动空白处 |
| 缩放 | 滚轮（以光标为中心） |
| 微调节点位置 | 「移动节点」模式，直接拖红点 |
| 新增道路 | 「加点/连线」：点空白=新建节点，点节点=开始连线，再点另一节点=成边（右键/ESC 取消） |
| 删除 | 「删除」：点节点=删节点及其所有边；点边=删边；点水域/建筑内部=删整个多边形 |
| 补水域/建筑 | 选「水域多边形」或「建筑多边形」→ 点「新建多边形」→ 沿卫星图轮廓依次点击顶点 → 双击最后一个点完成 |
| 修改多边形形状 | 拖动顶点微调；双击顶点=删除该顶点（少于 3 点自动删多边形） |
| 撤销 | Ctrl+Z 或顶栏按钮（最多 60 步） |
| 导出 | 点「导出 roadnet.json」→ 下载后替换 `happyrun/roadnet.json`（替换前备份原文件） |

## 导出后的校验流程（重要）

1. 把下载的 `roadnet.json` 覆盖到 `happyrun/roadnet.json`（旧文件先改名备份）；
2. 双击 `DryRun校验.bat` 跑一次干跑，确认无报错；
3. 打开 `tools/refine/final-full.png` 对照看整网效果；
4. 一切正常后再用「开始跑步.bat」正式跑。

## 注意

- 打卡点（品红圈）默认不要动——它们是服务端下发的固定坐标，移动后仍会被服务端原值校验（距离 100m 内判定）。
- 顶栏「恢复初始」= 回到打开编辑器时的状态（重新读的不是磁盘文件，只是内存初始值）。
- 导出前看底部状态栏有没有孤立节点提示；孤立节点不影响运行但最好删掉。
- 若以后想换更新/更大的底图：`node tools/editor-build.mjs --refetch` 重新抓取并重建编辑器。
